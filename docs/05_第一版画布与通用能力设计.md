# 审计数工坊：画布与通用能力设计

> 2026-10-26 方案基线，尚未按本方案完成界面改造。本版取代原文件中的七段审计导航、预置 JE／TB 画布作为默认入口，以及“公司配置为基本入口”的交互设想。旧程序及保存文件仍须兼容。产品定位见[产品目标](00_产品目标与边界.md)，批次见[开发路线](04_开发路线.md)，底层契约见[技术架构](06_技术架构与节点契约.md)。

## 1. 定位

审计数工坊首先是通用的数据清洗与处理工具。用户在同一张可执行画布上组合输入、结构整理、字段转换、筛选、追加、关联、汇总、检查和输出；针对审计资料优化复杂表格、金额与编码口径、异常去向、控制数和来源追溯。不按应付、费用、固定资产等单一场景分别开发完整程序，也不要求按固定审计阶段处理。场景和 Skill 用于发现能力缺口及构造验收样例，不成为产品主线。

输入可为单文件、不同用途的多文件（如 TB 与 JE）、多份同类但表头不同的文件，也可按同一逻辑逐家公司运行。几千行至数百万、乃至数千万行是架构目标；复杂 XLSX 的正确性与资源边界仍须单独检验。底稿自动上数、OCR 与 AI 建议不阻塞基础工具。

## 2. 窗口与默认入口

| 区域 | 职责 |
| --- | --- |
| 顶部 | 新建／打开／保存、按操作用途组织的工具分类与搜索、常用工具、校验、运行及状态。分类只帮助找工具，不规定执行顺序。 |
| 中央 | 新建后为空白的真实节点画布；示例仅在用户主动打开时载入。节点、端口、连线、分支与汇合决定执行。 |
| 所选节点配置 | 选中节点时显示对应可视表单；无选中时可收起。常用配置不要求写 JSON，高级选项按需展开。 |
| 结果区域 | 按需显示当前节点的字段、局部预览、运行后的全量控制数、异常、未纳入、来源和消息；空白或未运行时不长期占据大块画布。 |

面板须可收起、可调整尺寸；最终摆放和尺寸通过原型与人工使用验收。取消左侧编号的“文件接入 → 结构整理 → 字段整理 → 行处理 → 多表处理 → 结果检查 → 输出”固定导航，因为类别会交叉出现。审计常用操作可作为推荐或可选模板，但不建立第二套执行流程。

## 3. 从空白到输出的一次完整操作

1. 用户点“选择文件开始”或添加文件输入节点，直接在该节点选本地文件和工作表。节点显示文件名、绑定状态、原始行列和按物理行定位的局部预览。普通表只显示必要设置；复杂表可展开表头行、明细范围、真实合并区域等配置。原始值和位置保留。
2. 用户连接字段选择／映射节点。表单从上游取得实际列名，以“保留、原列名、输出列名、类型”呈现；显示缺列、重名和类型冲突。字段映射可用于追加等后续步骤，只依据实际上游结构校验，不限于文件输入附近。
3. 用户继续添加筛选、转换、计算、标记、追加、关联等节点。常用操作有对应表单；连线决定来源，多输入节点明确左右或命名端口，不能靠隐藏的资料代号或 JSON 决定执行来源。
4. 选中任一步，可分别看局部预览与全量运行证据。清洗动作应显示受影响行、原值和前后差异；配置、文件或上游结构改变后，旧预览及旧运行结果须失效或明确标为旧结果。
5. 输出节点明确格式和位置。保存、重开后画布、规则及本地绑定一致；源文件内容变化时提示重新确认。原始数据不复制进流程定义。

画布须支持选择、真实鼠标拖动、连接与改线、线上插入、删除、撤销／重做、分支、多输入与多输出端口。缺连接、缺参数或字段无效须定位到节点并在运行前提示。节点形状与连线显示不是功能验收；必须由用户不看 JSON、不打开预置模板，仅用界面从选文件走到导出并保存重开。

## 4. 通用操作范围

每个操作至少说明输入结构、可视参数、正常与异常输出、行数及金额影响、原始位置和复核方式。定义范围不等于已实现。

| 能力组 | 操作 |
| --- | --- |
| 文件与表结构 | 单文件和文件组输入、工作表选择、数据区域定位、多层表头、真实合并区域、空行及尾部合计／说明处理 |
| 字段与文本 | 选列、调序、重命名、可重复使用的字段映射、文本拆分／提取／替换、空格及特殊字符清理、金额／日期／编码转换 |
| 逐行与跨行 | 筛选、排序、去重且保留重复项、计算列、辅助标记、按组前后行引用、累计计算、排名和顺序编号 |
| 多表与形状 | 同类纵向追加、按键关联、查表补值、分组汇总、宽转长、长转宽、分支与汇合 |
| 检查与输出 | 缺列、类型、重复键与未匹配检查；行数和金额控制数；两表差异；正常、异常及未纳入结果导出和来源反查 |

合并单元格、纵向追加、按键关联是三种不同能力。发现重复、空值或异常金额不等于自动删除或填补；筛选和配对可先产生标记，排除须由用户明确设置。文本语义、模糊匹配及 AI 判断不作为基础操作前置条件。

## 5. 多文件、复用与规模

- 同格式文件可在输入节点选择文件组，逐份保存来源，追加前核对列名和类型；异构同类文件各自整理、映射后再显式追加，不按列位置静默拼接。
- TB、JE 等不同用途资料各自成支路，再由关联或比较节点明确键、金额及左右输入；跨公司合并必须显式选择并保留主体身份。
- 普通处理项目可一并保存流程和本地输入绑定。需要批量或跨公司复用时，再从已完成流程另存模板、指定多组绑定并分别运行。单文件处理不以建立公司配置为前提，旧运行证据不因后来编辑画布而改变。
- 界面仅分页取局部数据；Rust 接入、DuckDB 执行同一套节点语义，不按行数切换第二套业务规则。大结果不默认限定 Excel 输出，不承诺无上限。
