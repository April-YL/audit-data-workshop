### 内容走查明细

- 异构追加：沿m.map→m.append明确列对应、单位与来源；类型转换仅按确认格式，不由字段外观推断。
- 关联：沿m.join检查右侧键唯一性，保留左交易，未匹配和右未使用分别解释。
- 单表处理：沿m.filter→m.dedupe→m.aggregate依次过滤状态、按明确版本保留、按部门汇总发生额；移除记录仍有去向。
- 信息不足：m.dedupe与m.aggregate的参数要求可识别身份、保留方式和金额口径缺口；案例的expected只是人工基准，未来需模型实测是否正确追问。
- 规则冲突：币种、单位和时间口径不一致时阻断受影响汇总，建议分别列示或取得明确换算依据；不作跨准则自动裁决。

### 可复查命令

使用架构文档的PowerShell解析命令可复查JSON格式。以下Python片段在工作区根运行，检查所有ID和引用；解释器使用实际Python 3路径（本机python别名可能指向不可执行的WindowsApps占位程序）。

```python
from pathlib import Path
import json
root = Path("审计数工坊/code/ai-knowledge")
data = [json.loads(p.read_text(encoding="utf-8")) for p in root.glob("*.json")]
collections = {"sources", "knowledge_items", "concepts", "relations", "constraints",
               "document_profiles", "system_profiles", "methods", "walkthrough_cases"}
ids = {}
for doc in data:
    for name, items in doc.items():
        if name in collections:
            for item in items:
                assert item["id"] not in ids
                ids[item["id"]] = name
ref_types = {"source_id": "sources", "concept_ref": "concepts",
             "from_concept": "concepts", "to_concept": "concepts",
             "concept_refs": "concepts", "related_concepts": "concepts",
             "method_refs": "methods", "knowledge_refs": "knowledge_items",
             "constraints": "constraints"}
refs = []
def check(value):
    if isinstance(value, dict):
        for name, child in value.items():
            values = child if isinstance(child, list) else [child]
            if name in ref_types and all(isinstance(v, str) for v in values):
                for ident in values:
                    assert ids.get(ident) == ref_types[name], ident
                    refs.append(ident)
            check(child)
    elif isinstance(value, list):
        for child in value:
            check(child)
for doc in data:
    check(doc)
print(len(ids), len(refs))  # 0.1.0预期：121 426
```
