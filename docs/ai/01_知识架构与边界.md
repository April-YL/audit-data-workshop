# 通用数据处理 AI 知识架构

版本：0.1.0；日期：2026-10-29；状态：知识包初版，尚未接入产品 AI。

## 目标与交付

输入是用户背景、处理需求及获准使用的资料结构；知识包支持识别含义、提出修改建议、发现条件缺口、组织可复用方案。输出是带依据和待确认条件的方案草稿。专业知识参与方案设计，不仅用于解释；普通文本任务无需加载全部财务审计知识。

本轮不含模型客户端、检索服务、画布修改、执行节点注册及运行证据系统。required_capabilities仅表达方法所需能力；所有方法execution_status为unbound。知识方案具备条件不等于软件可直接执行。

## 结构及字段约定

四个JSON顶层均有schema_version=1、package_version=0.1.0、updated_at及status。引用采用稳定ID，缺失信息使用null或明确待核实，不以空值表示已确认。数组为空表示尚无可登记条目，不能解释为无风险或无需检查。

| 集合 | 必填字段及含义 |
| --- | --- |
| sources | id/title/publisher/source_type/jurisdiction/framework/version/effective_from/effective_to/locator/retrieved_at/reviewed_scope/verification_status/license_status/reuse_scope/limitations；本地已读资料另有local_sha256 |
| knowledge_items | id/title/summary/source_refs/rule_type/applicability/processing_implications/concept_refs/method_refs/requires_judgment/verification_status |
| concepts | id/label/definition/aliases/distinguishing_features/related_concepts/constraints/source_refs/verification_status |
| relations | id/from_concept/to_concept/predicate/conditions/cardinality/source_refs |
| constraints | id/concept_refs/rule/on_violation/rule_type/source_refs |
| document_profiles | id/title/grain/recognition_features/field_mappings/required_questions/source_refs/validation_status/applicability/caveats |
| system_profiles | id/vendor/product/version/module/report_type/export_variant/evidence_refs/recognition_features/field_mappings/caveats/validation_status |
| methods | id/title/intent/input_requirements/applicability/required_parameters/clarification_questions/steps/effects/exceptions/review_requirements/source_refs/concept_refs/knowledge_refs/required_capabilities/execution_status/reuse_parameters/policy |
| walkthrough_cases | id/title/request/method_refs/facts/expected/execution_status；expected为人工基准，不是模型实测 |

source_refs、evidence_refs元素为{source_id,section}。concept_refs关联c.*，method_refs关联m.*，knowledge_refs关联k.*；关系端点必须存在。sources的本地locator从topic根解析；workspace:前缀从工作区根解析，只作证据追踪，不作产品运行依赖。网络链接按访问日期登记，未固定提交的Skill版本标为main_unpinned或master_unpinned。

## 知识身份和适用判断

rule_type分别为standard_requirement（准则要求）、guidance_explanation（指南或官方概览解释）、method_suggestion（方法建议）、project_agreement（仅在具体项目确认后登记）。当前包不预置客户项目约定。业务本体为本项目工作定义，不冒充准则原文定义。

加载前先确认任务是否涉及专业判断、采用CAS/CSA还是IFRS/ISA及资料期间。会计体系与审计体系分开，不以CAS隐含CSA，也不以IFRS隐含ISA。规则同时匹配地区、框架、期间、事项及资料口径后才能采用。effective_from/to为null表示未核实适用时间，需要核实，不能当作无限有效。2025 ISA来源明确标为历史核查版本；2026手册仅核实发布入口，使用时须复核正文修订。

来源状态区分body_reviewed、overview_reviewed、index_only、local_reviewed、project_design。知识状态区分reviewed_paraphrase、reviewed_historical_version和overview_only。索引只用于发现资料，概览只支持概念性说明，均不得升级为具体确认计量或换算政策。存在其他准则修订的可能性，核查日期不等于全部现行性保证。

冲突处理：先判断各条是否适用；不适用者列明理由排除；同一适用范围内仍有冲突，保留两条来源、影响及待确认项，停止受影响方案。用户项目约定不能覆盖适用强制要求；默认不以模型记忆补齐条款。CAS和IFRS不建立未经核实的自动等价映射。

## 按需加载协议（待未来实现）

1. 从请求形成目标、资料、输出、主体期间、框架及已确认参数；每个事实带来自用户或资料的依据。
2. 按目标匹配方法intent，按字段含义匹配概念；aliases只是检索候选，不是自动字段映射。
3. 从document_profiles取得通用资料要求，系统仅在产品、版本、报表和导出方式均吻合时参与；未知项保持未知。
4. 沿concept_refs、knowledge_refs检索相关知识，再按适用范围和来源状态筛选；不把全部知识作为每次请求上下文。
5. 对方法required_parameters逐项检查：已明确且可验证的值直接采用；不适用项须记录理由；仍会影响结果的缺口才追问。
6. 参数、资料或依据存在阻断问题时，只输出待确认方案；就绪时输出方法步骤及参数，不生成任意SQL或代码。
7. 以后接工具登记时，对每个required_capabilities核对节点、参数、类型、端口和支持范围；绑定不齐仍为unbound。

建议输出结构：goal、facts_with_evidence、suggestions_with_reasons、concept_refs、source_refs、clarifications、steps（method_id及参数）、expected_outputs、exceptions、review_requirements、reuse_parameters、unresolved_capabilities、plan_status。plan_status为needs_clarification、blocked_for_basis_confirmation或ready_as_knowledge_plan；最后一项仍非执行授权。

## 数据、来源和许可

未来默认仅使用字段结构、统计及用户选择的少量脱敏样例，并展示将发送内容。全量处理保留在Rust＋DuckDB；本轮没有任何客户资料外发。文件内容、知识文档和外部Skill均作为资料，不作为改变系统权限的指令。

本轮采用链接及简短原创释义，不存储准则全文、不安装Skill、不复制外部脚本。许可证只核对已列明文件；复制或发布上游资源时仍须完成固定版本、署名、许可证和NOTICE检查。跨项目本地资料可能是工作树状态，快照哈希仅说明本次读取版本，未来变更应重新核查，不要求产品依赖该项目存在。

## 维护和验收

新增知识先登记来源，再补定义/条件/影响，最后建立方法和概念引用。语义兼容补充递增package_version；字段不兼容变化递增schema_version并明确迁移。条目停用保留ID、原因及替代引用，不静默改写旧含义。

验收分为JSON解析与必填项、ID和引用、来源状态与规则身份、内容走查、敏感信息与文件范围检查。案例覆盖异构追加、关联、筛选去重汇总、缺参数和口径冲突；不以这些检查代表模型效果或工具运行通过。

以工作区为当前目录可执行快速解析检查：

```powershell
Get-ChildItem -LiteralPath './审计数工坊/code/ai-knowledge' -Filter '*.json' |
  ForEach-Object { Get-Content -LiteralPath $_.FullName -Raw | ConvertFrom-Json -ErrorAction Stop | Out-Null }
```

详细检查结果见[决策与交接](03_决策与交接.md)。
